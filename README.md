Lovely Box – Gifts Website

Lovely Box is a gift-box website that helps customers explore ready-made gift collections, create a personal gift, and contact the shop to place an order.

✨ Features

* Home Page: Introduction to Lovely Box and its gift options.
* Ready-Made Gifts: Browse gift collections with images, descriptions, and starting prices.
* Custom Gifts: Explore personalized gift options.
* Gift Quiz: Get gift suggestions based on the occasion, recipient, and preferred style.
* How It Works: Learn about the ordering process.
* FAQ: Find answers to common questions.
* WhatsApp Ordering: Contact the shop using pre-filled WhatsApp messages.

🚀 Run Locally

No package installation or build process is required.

1. Clone the repository:

git clone https://github.com/starboy679/Lovely_Box-GiftsWebsite.git

2. Open the project folder.
3. Open index.html in your browser.

You can also use Visual Studio Code with the Live Server extension.

🛍️ Ordering

Customers can browse the available gift boxes, use the Gift Quiz for suggestions, and contact Lovely Box through WhatsApp to enquire or place an order.
